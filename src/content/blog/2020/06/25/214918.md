WebWorkerのスクリプトを別ファイルではなくバンドルファイルに含めたい場面があったので、インラインで記述する方法を試しました。

[Web Worker の使用](https://developer.mozilla.org/ja/docs/Web/API/Web_Workers_API/Using_web_workers)

blob経由でworkerスクリプトのオブジェクトURLを生成することによって実現させました。

```javascript
const workerCode = `
onmessage = function(e) {
  console.log('worker thread: onmessage');
  console.log(e)
}
`;

const workerScript = URL.createObjectURL(
  new window.Blob([workerCode], { type: "application/javascript" })
);

const worker = new Worker(workerScript, { name: "test" });

worker.postMessage(["test"]);
```

[https://gist.github.com/takumifukasawa/793219744af4cf0ba7462065014a26f3](https://gist.github.com/takumifukasawa/793219744af4cf0ba7462065014a26f3)

ただ欠点として文字列での記述になるので、

-   エディターのsyntaxが利かない
-   typescriptの場合は型指定ができない

という点があります。

WebWorkerのスクリプトの記述量が多くなりそうな場合は別ファイルにしておくのが良さそうです。
