- 開始: 2026-11-27
- 状態: 進行中（2026-11-27 に「データを移しながら組み換えてみる」で合意。タスク 1〜3 済み、次はタスク 4）
- 関連: `spec/site-v0.md`（P1.5 の Notes を前倒しで拡張する）、`spec/content-model.md`（notes）、`decisions/0004-lab-shell.md`

## 目的（何ができれば完了か）

はてなブログの記事をすべてこのサイトへ移し、このサイトで記事も daily 的な短文も書けるようにする。
はてな側の旧 URL から新 URL へ人も検索エンジンも辿れる。その上で AdSense のサイト審査に出せる状態にする。

## 受け入れ条件

- [ ] はてなの公開記事がすべてサイトにあり、旧 URL → 新 URL の対応表が repo にある（件数が一致することを script で確認）
- [x] 対応表の新 URL がすべて 200 を返す（script で確認。2026-11-27）
- [ ] はてな側の旧 URL を開くと新 URL へ移る（JS のリダイレクト + canonical）。本文は移転案内に差し替わっている
      2026-11-27: 移る方は済（42 本に script、スマホ表示にも入っている。記事・日付 URL・`#` 付き・アーカイブを実ブラウザで確認）。本文は未定
- [ ] 記事の画像がはてなフォトライフに依存しない
- [ ] 記事ページが `header` / `nav` / `main` / `article` / `footer` の構造を持つ
- [ ] プライバシーポリシーのページと `ads.txt` がある
- [ ] `harness check --full` が通る

## たたき台（タスク 4 で実データを見て決め直す）

| `/`（作品グリッド） | sketch | 無し（作品へ直接） |

## 決定ログ（日付・決めたこと・理由・落選案）

- 2026-11-27: **はてなの記事は全部移す。** 理由: AdSense の審査に記事の本数が要る、検索流入は小ネタ記事の方が多い、置き場が 1 つになる、42 本なら変換は一度で済む。
  落選案: 作品・グラフィックス寄りの約 15 本だけ移す（「あの記事はどっち」が続く。審査の本数も足りない）、はてなを凍結して移さない。
- 2026-11-27: **はてな側は JS のリダイレクト + canonical と、本文の移転案内への差し替えの二段構え。ブログ自体は消さない。**
  サブドメイン（`*.hatenablog.com`）なので 301 は出せない。「詳細設定 → `<head>`要素にメタデータを追加」に script を置けることを確認済み（2026-11-27）。
  落選案: 記事の削除（被リンクが全部 404 になる）、Search Console のアドレス変更ツール（サイト単位の 301 が前提で使えない）。
- 2026-11-27: **広告は記事ページだけに出す。** 作品ページ（`_shell.js`）とトップには出さない。全画面の作品に重なると作品が壊れ、ポートフォリオとしての見え方も悪い。
- 2026-11-27: **作品ページのヘッダーは当面 `_shell.js` のまま。** 広告を出さないので審査に関係せず、Googlebot は JS と Shadow DOM を読む。
  静的なマークアップにしたくなったら、Cloudflare の配信時に差し込む（Worker の HTMLRewriter）。正本はサイト側の 1 か所のまま。
  落選案: 全件を再ビルドして焼き込む（決定 0004 の「1 ファイルで全作品に反映」が崩れる）、コミット済みの HTML を script で書き換える（500 ファイルの差分、`lab build in sync` と衝突）。
- 2026-11-27: **Claude とのセッションを作品ごとの記事にするのは後回し。** やる時は、ユーザーの発言はそのまま、Claude は抜粋、自分のコメントを少し挟む形。
  載せる前に漏洩の検査（絶対パス・メール・他プロジェクト名）を通す。生ログをそのまま載せない（長すぎる・漏洩・AdSense で低品質と見なされやすい）。

- 2026-11-27: **URL は `/blog/<はてなの BASENAME>/`。** リダイレクトを規則だけで書けるようにするため（`/entry/X` → `/blog/X/`）。
  日付 URL の 7 本も `/blog/2021/06/19/133849/` のまま引き継ぐ。落選案: 日付 URL の 7 本に新しい slug を付ける（リダイレクトに対応表が要る。見た目のために後から付け替えるなら、サイト側の `_redirects` で足せる）。
- 2026-11-27: **移すのは `takumifukasawa.hatenablog.com` の公開記事だけ。** 下書き 14 本、`study-art` と `diary` のブログは移さない（人間の判断）。
- 2026-11-27: **変換の方針。** はてなキーワードのリンクは外す、リンクカードと CodePen・YouTube の埋め込みは普通のリンク、gist はコードを本文に取り込む、
  目次（`[:contents]`）は消す、それ以外の script も消す。外部の script や iframe を記事に残さない。2 MB を超える GIF はアニメーション WebP にした（5 枚。Astro のビルドでもアニメーションが残ることを確認）。

- 2026-11-27: **CodePen と YouTube の埋め込みは、クリックで読み込む形にする（8 本・12 か所）。** 最初は枠と ▶ と元へのリンクだけを出し、押したら iframe に差し替える。
  YouTube は `youtube-nocookie.com` から読み込む。サムネイルは付けない（CodePen のサムネイルは自動で取れない。403 が返る）。
  落選案: リンクだけ（記事の要のデモが見えない）、最初から埋め込む（開いただけで外部の読み込みと Cookie が発生し、CodePen が 3 つある記事は重い）。
  リンクカードはリンクのまま。自前のカード（ビルド時に OGP を取る）はタスク 4 で見た目を決めるときに考える。
- 2026-11-27: **記事の外部リンクは新しいタブで開く**（ヘッダーの外部リンクと同じ）。Astro 7 の既定の Markdown 処理（Sätteri）用のプラグインを `astro.config.ts` に書いた。
- 2026-11-27: **太字・斜体の記号が日本語の句読点に接すると閉じない**（CommonMark の flanking の規則）ので、その場合だけ `<strong>` / `<em>` を残す。

- 2026-11-27: **はてなに入れるのは head の script だけを先に。本文の差し替えは後回し。** script は旧 URL の canonical を新 URL に向けてから `location.replace` する。
  外せば元に戻る（はてなの記事は手つかずのまま残る）。本文の差し替えは記事 42 本を書き換える不可逆に近い操作で、canonical で重複は解消するので、
  script で移れることを確かめてから要るかを決める。落選案: 最初から本文も差し替える（戻すのが大変で、はてな側が唯一の控えでもある）。

- 2026-11-27: **sitemap は `src/pages/sitemap.xml.ts` で自前に出す。** ビルドのたびに blog と lab の collection から作るので、記事や sketch を足しても手で直す必要はない。
  `.astro` のページを新しく足したときだけ、固定の行に 1 行足す。落選案: `@astrojs/sitemap`（Astro が生成したページしか見ないので、`public/lab/` の作品が漏れる）。
  `public/robots.txt` から参照する。
- 2026-11-27: **はてなの head から AdSense のタグを外した**（全ページがすぐ移るので広告が出る前に離れる。人間の判断）。
