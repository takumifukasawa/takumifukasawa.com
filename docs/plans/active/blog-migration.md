# blog — はてなブログを移してサイトにブログを持つ

- 開始: 2026-11-27
- 状態: 計画中（2026-11-27 に「データを移しながら組み換えてみる」で合意。タスク 1 は人間のエクスポート待ち）
- 関連: `spec/site-v0.md`（P1.5 の Notes を前倒しで拡張する）、`spec/content-model.md`（notes）、`decisions/0004-lab-shell.md`

## 目的（何ができれば完了か）

はてなブログの記事をすべてこのサイトへ移し、このサイトで記事も daily 的な短文も書けるようにする。
はてな側の旧 URL から新 URL へ人も検索エンジンも辿れる。その上で AdSense のサイト審査に出せる状態にする。

## 受け入れ条件

- [ ] はてなの公開記事がすべてサイトにあり、旧 URL → 新 URL の対応表が repo にある（件数が一致することを script で確認）
- [ ] 対応表の新 URL がすべて 200 を返す（script で確認）
- [ ] はてな側の旧 URL を開くと新 URL へ移る（JS のリダイレクト + canonical）。本文は移転案内に差し替わっている
- [ ] 記事の画像がはてなフォトライフに依存しない
- [ ] 記事ページが `header` / `nav` / `main` / `article` / `footer` の構造を持つ
- [ ] プライバシーポリシーのページと `ads.txt` がある
- [ ] `harness check --full` が通る

## たたき台（タスク 4 で実データを見て決め直す）

| 置き場 | 中身 | 1 件ずつのページ |
|---|---|---|
| `/`（作品グリッド） | sketch | 無し（作品へ直接） |
| ブログ（1 列） | 移した記事 + daily の短文 +（あれば）sketch を日付順 | 長い記事は有り。短文は一覧に全文を出し、個別ページは作らない（中身の薄いページを量産しない） |

参考: saqoo.sh/a/（日付 + カテゴリ + 1 文を 1 列に並べる。`header` / `main` / `section` / `h2` / `ul` の素直な構造）。

## 決定ログ（日付・決めたこと・理由・落選案）

- 2026-11-27: **はてなの記事は全部移す。** 理由: AdSense の審査に記事の本数が要る、検索流入は小ネタ記事の方が多い、置き場が 1 つになる、42 本なら変換は一度で済む。
  落選案: 作品・グラフィックス寄りの約 15 本だけ移す（「あの記事はどっち」が続く。審査の本数も足りない）、はてなを凍結して移さない。
- 2026-11-27: **はてな側は JS のリダイレクト + canonical と、本文の移転案内への差し替えの二段構え。ブログ自体は消さない。**
  サブドメイン（`*.hatenablog.com`）なので 301 は出せない。「詳細設定 → `<head>`要素にメタデータを追加」に script を置けることを確認済み（2026-11-27）。
  落選案: 記事の削除（被リンクが全部 404 になる）、Search Console のアドレス変更ツール（サイト単位の 301 が前提で使えない）。
- 2026-11-27: **広告は記事ページだけに出す。** 作品ページ（`_shell.js`）とトップには出さない。全画面の作品に重なると作品が壊れ、ポートフォリオとしての見え方も悪い。
- 2026-11-27: **作品ページのヘッダーは当面 `_shell.js` のまま。** 広告を出さないので審査に関係せず、Googlebot は JS と Shadow DOM を読む。
  静的なマークアップにしたくなったら、Cloudflare の配信時に差し込む（Worker の HTMLRewriter）。正本はサイト側の 1 か所のまま。
  落選案: 全件を再ビルドして焼き込む（決定 0004 の「1 ファイルで全作品に反映」が崩れる）、コミット済みの HTML を script で書き換える（500 ファイルの差分、`lab build in sync` と衝突）。
- 2026-11-27: **Claude とのセッションを作品ごとの記事にするのは後回し。** やる時は、ユーザーの発言はそのまま、Claude は抜粋、自分のコメントを少し挟む形。
  載せる前に漏洩の検査（絶対パス・メール・他プロジェクト名）を通す。生ログをそのまま載せない（長すぎる・漏洩・AdSense で低品質と見なされやすい）。
